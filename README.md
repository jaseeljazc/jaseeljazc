## About

I'm a full stack developer with 1+ year of hands-on experience building and deploying production web applications with **Next.js, React, TypeScript, Node.js and PostgreSQL**.

I work AI-native: Claude Code, OpenCode, Antigravity and Hermes Agent, with agents, MCP, custom skills and context engineering. I still own the architecture, business logic, code review, manual testing and deployment myself.

I designed and built the **Betterinu** platform on my own: a student LMS, an employee admin panel and a marketing website. It has been in production since May 2026, with 30+ students and 10+ employees using it.
